## Design Philosophy
Soft Luxury, Modern Minimalism, Elegant and Timeless.
## Colors
- Primary: #E8B4C0
- Primary Light: #F9E9ED
- Background: #FFFFFF
- Accent Gold: #D4AF72
- Text Primary: #332A2D
- Text Secondary: #8B8385
- Border: #F0E3E6
## Typography
- Font: Inter
- Headings: SemiBold
- Body: Regular
- Buttons: Medium
## Components
- Card Radius: 18px
- Button Radius: 14px
- Input Radius: 12px
- Standard Spacing: 8px
- Card Padding: 16px
- Subtle Shadows
- Thin Borders
## Buttons
- Primary: Dusty Rose background
- Secondary: White background with rose border
- Accent: Champagne Gold used sparingly
## Layout
- Mobile First
- White dominant backgrounds
- Generous whitespace
- Consistent bottom navigation
- Accessible touch targets
## Rules
- Never use neon pink.
- Never overuse gold.
- Avoid heavy gradients.
- Maintain consistent components across screens.
- All interface text must be in French.
