## Design Philosophy
Soft Luxury, Modern Minimalism, Elegant and Timeless for PeMS Store - Application mobile professionnelle de gestion commerciale de boutiques de chaussures au Cameroun (FCFA).

## Colors
- Primary: #E8B4C0 (Dusty Rose)
- Primary Light: #F9E9ED (Soft Rose Tint)
- Background: #FFFFFF (Pure White)
- Accent Gold: #D4AF72 (Champagne Gold)
- Text Primary: #332A2D (Deep Espresso Rose)
- Text Secondary: #8B8385 (Muted Mauve Gray)
- Border: #F0E3E6 (Soft Rose Border)
- Surface Light: #FAFAFA
- Surface Card: #FFFFFF
- Success: #34A853
- Warning: #FBBC04
- Error: #EA4335

## Typography
- Font: Inter / Plus Jakarta Sans
- Headings: SemiBold (600)
- Body: Regular (400)
- Buttons: Medium (500)

## Components
- Card Radius: 18px
- Button Radius: 14px
- Input Radius: 12px
- Standard Spacing: 8px
- Card Padding: 16px
- Subtle Shadows: 0 4px 20px rgba(232, 180, 192, 0.12)
- Thin Borders: 1px solid #F0E3E6

## Buttons
- Primary: Dusty Rose (#E8B4C0) background with #332A2D text
- Secondary: White background with rose border (#F0E3E6)
- Accent: Champagne Gold (#D4AF72) used sparingly

## Layout
- Mobile First (Android, ~390px)
- White dominant backgrounds
- Generous whitespace
- Consistent bottom navigation
- Accessible touch targets (min 48px)

## Rules
- Never use neon pink.
- Never overuse gold.
- Avoid heavy gradients.
- Maintain consistent components across screens.
- All interface text must be in French.
- Currency: FCFA.
